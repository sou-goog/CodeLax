# CodeLax ML Pipeline

Fine-tunes `microsoft/codebert-base` to classify finding severity (CRITICAL / HIGH / MEDIUM / LOW) using your own Neon database as the training source.

## Files

| File | Purpose |
|---|---|
| `prepare_data.py` | Pull findings from Neon → balanced CSV |
| `train_severity_classifier.py` | Fine-tune CodeBERT on Kaggle T4 |
| `requirements.txt` | Python dependencies |

## Step-by-step

### Step 1 — Export data from your Neon DB (run locally)

```bash
cd ml/
pip install -r requirements.txt

# If you have real reviews in Neon:
python prepare_data.py

# If DB is empty or has < 40 rows, add synthetic seed examples:
python prepare_data.py --seed
```

This writes `findings_dataset.csv` with columns: `text`, `label`, `severity`, `source`.

### Step 2 — Upload to Kaggle

1. Go to [kaggle.com/code](https://www.kaggle.com/code) → **New Notebook**
2. Enable **GPU T4 x2** (or x1) under Settings → Accelerator
3. Upload `findings_dataset.csv` as a Dataset
4. Paste the contents of `train_severity_classifier.py` into a code cell
5. Add this install cell at the top:

```python
!pip install -q transformers datasets evaluate accelerate
```

6. Run all cells. Training takes ~15 min on T4.

### Step 3 — Download the model

After training, the model is saved to `./severity_classifier/`. Download it as a zip.

### Step 4 — Use in CodeLax

The `SeverityClassifier` class in `train_severity_classifier.py` is your inference API:

```python
from train_severity_classifier import SeverityClassifier

clf = SeverityClassifier("./severity_classifier")
result = clf.predict("[AGENT] security [TITLE] SQL Injection ...")
# → {"label": "CRITICAL", "score": 0.97, "all_scores": {...}}
```

Hook this into your critic or specialist agents via a Python sidecar (FastAPI/Flask) that your Next.js backend calls.

## Why this approach is stronger than a generic Kaggle dataset

- **Your data**: findings were generated by *your* multi-agent pipeline and verified by *your* critic
- **Schema-aligned**: the text format matches exactly what the agents produce at inference time
- **Self-improving loop**: every new CodeLax review generates more training data automatically
- **No data leakage**: test split is stratified and held out from training

## Metrics to expect

| Metric | Target |
|---|---|
| Weighted F1 | ≥ 0.80 with synthetic seed only |
| Weighted F1 | ≥ 0.88 with 200+ real DB rows |
| Accuracy | ≥ 0.82 |
